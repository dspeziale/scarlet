    SCARLET

    System Container Application Release, Lifecycle & Environment Tool — version {{ scarlet_version }} ({{ scarlet_env }}).

    SCARLET is a control plane: operators declare the desired state of an application on a target (version, running/stopped); the deployment engine drives the actual state toward it through a runtime adapter (Docker, Podman, Kubernetes) over SSH, and the reconciler reports drift.
