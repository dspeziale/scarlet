# Font dei manuali PDF

I PDF in `docs/pdf/` sono composti in **PT Sans Narrow** (testo) e **PT Mono** (comandi),
entrambi di ParaType e distribuiti con licenza SIL Open Font License 1.1 (`OFL.txt`), che ne
consente l'uso e la ridistribuzione anche in documenti commerciali.

| File | Uso |
|---|---|
| `PT_Sans-Narrow-Web-Regular.ttf` | testo corrente, tabelle, diagrammi |
| `PT_Sans-Narrow-Web-Bold.ttf` | titoli, intestazioni di tabella, grassetto |
| `PTMono-Regular.ttf` | comandi, percorsi, nomi di campo |

I file sono versionati apposta: la build dei PDF non scarica nulla e produce lo stesso
risultato su qualsiasi macchina. Origine: <https://github.com/google/fonts> (`ofl/ptsansnarrow`
e `ofl/ptmono`).
